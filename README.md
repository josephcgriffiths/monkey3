# Writing an Interpreter in Go

This repository contains my implementation while following *Writing an Interpreter in Go*.  
The goal of the project was to gain a deeper understanding of language design, parsing, and interpreter architecture.

## Overview
By working through the book, I implemented the core components of a simple programming language, focusing on how source code is transformed and executed.

Key areas explored include:
- Lexical analysis (tokenisation)
- Parsing using a Pratt parser
- Abstract Syntax Tree (AST) construction
- Basic interpreter evaluation logic

The emphasis of this project is on understanding concepts and implementation details rather than extending the language with additional features.

## What I Learned
- How lexers convert raw source text into tokens
- How Pratt parsing handles operator precedence and expression parsing
- Structuring an interpreter in Go
- Translating language theory into practical, working code

## Notes
This project closely follows the structure and guidance of the book. Any deviations or experiments were made to better understand specific concepts rather than to significantly alter the original design.
